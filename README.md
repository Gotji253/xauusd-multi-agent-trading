# XAUUSD Multi-Agent AI Trading System\n\n**ระบบ Multi-Agent AI Trading สำหรับทองคำ (XAUUSD)**  \nออกแบบโดยเน้น **Risk-Adjusted Return** และ **ควบคุม Drawdown** เป็นหลัก\n\n**Repository**: https://github.com/Gotji253/xauusd-multi-agent-trading\n\n---\n\n## รันบนเบราว์เซอร์ (GitHub Codespaces)\n\n1. เปิด https://github.com/Gotji253/xauusd-multi-agent-trading\n2. กด **<> Code** → **Codespaces** → **Create codespace on main**\n3. รอ 1–3 นาที แล้วรัน:\n\n```bash\npip install -r requirements.txt\npytest tests/ -v\npython run_backtest.py\n```\n\n---\n\n## สิ่งที่พัฒนาแล้ว\n\n### 1. Technical Analysis Agent (สมบูรณ์)\n- Multi-timeframe: M15 (entry) + H1 (trend bias)\n- Indicators: EMA20/50/200, RSI(14), ATR(14)\n- Confluence scoring ≥ 0.55 ถึงจะสร้าง Signal\n- H1 Bullish/Bearish filter + Pullback to EMA20 + RSI recovery/rejection\n\n### 2. Backtest Engine + กราฟ\n```bash\npython run_backtest.py\n```\nสร้าง:\n- `backtest_output/equity_and_trades.png` — Equity curve + Drawdown + Trade PnL\n- `backtest_output/price_signals.png` — ราคา + EMA + RSI + จุดเข้า-ออก\n\n### ผลทดสอบ (synthetic data)\n- 16 unit tests ผ่านทั้งหมด\n- Backtest รันได้จริง (ใช้ Agent จริงของระบบ)\n\n> ข้อมูล synthetic ใช้ทดสอบระบบเท่านั้น ไม่ใช่การันตีกำไรจริง\n\n---\n\n## โครงสร้างหลัก\n\n```\nagents/technical_analysis.py   ✅ Signal จริง\nagents/risk_management.py      ✅\nbacktest/engine.py             ✅\nbacktest/charts.py              ✅\nrun_backtest.py                ✅\ntests/                         16 tests ผ่าน\n```\n\n---\n\n## ขั้นตอนถัดไป\n\n- โหลดข้อมูลจริงจาก MT5 / CSV\n- Execution Agent บน Windows VPS\n- Paper Trading\n\n**Risk Management เป็นหัวใจ** — อย่าลดกฎความเสี่ยงโดยไม่ผ่าน Backtest\n
